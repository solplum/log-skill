# Agent Team Contract

主线程在材料较多或需要补证时按需并行派代理，受宿主并发能力约束。工作记录类可按源或项目分工，云端提交类宜按仓库分工；先说明类型、日期和取证边界。用户指定的记录已经足够时，不为凑源数量重新扫描或派任务。
**禁止编造**，未知归属、日期和状态明确标为未知；**禁止泄漏密钥**——素材里的密钥/token/密码一律脱敏或省略。被跳过的源不派代理、不产空草稿。

## 素材要求（所有 Agent 必遵）

1. **保留项目与仓库归属**：按实际项目、仓库或模块归组。跨仓功能分别说明各仓承担部分，不在各仓重复声称同一整体成果；不凑三仓或抽象业务类别。
2. **提供具体改动与证据**：说明改了什么、必要行为细节、已观察的验证结果及交付状态；不强制痛点—改动—效果，也不将调查或建议改写成已修复。
3. **核对日期与状态**：工作发生日期、会话活跃日期和补录日期分开；只保留用户选定范围内的实际进展。区分本地验证、提交、推送、发布和部署；只看到总结声明时不能假定有独立工具证明。
4. **准确且可读**：保留有辨认价值的仓库、模块和功能名，陌生代号补职能说明；省略 AI 调度和工具调试流水账，不把功能过度泛化为价值口号。

## 统一输出契约

素材可用表格或短条目，提供：

`周报类型 | 项目 | 仓库/模块 | 实际发生日期 | 贡献归属及依据 | 具体改动与必要细节 | 验证结果 | 交付状态 | 来源定位`

来源定位可为会话 ID、文件与行号或工具回执；归属、日期或结果未知时如实标注。主线程成稿时按“项目 → 功能主线 → 各仓具体改动”整合素材，来源定位留在素材，不必塞进周报正文。不要自行追加下周计划或套用固定三段、四段模板。

按主线程要求直接返回素材，或写到指定中间草稿；未经主线程分配，不写正式日志或周报。

## 云端提交类分工

- 读取 [cloud-weekly.md](cloud-weekly.md)，每个代理负责指定仓库的相关远端分支及范围内实际代码差异，不把本地未推送改动纳入。
- 素材保留远端 SHA、基线、关键路径及去重依据；已经合入发布分支的本周工作不因差集为空而漏记。
- 个人周报只提炼可确认的本人增量；核对提交身份、父节点差异及协作记录，分开带教/同事的基础能力与本人接入、适配或修复。推送者或分支名不证明贡献归属，归属不明不计入个人已完成成果。
- 同一功能的多分支改动去重整合，并说明各仓承担的部分，正文不按分支分组；同一提交、合并或 cherry-pick 去重，互斥实现不得虚构成统一版本。
- 只做远端与 Git 读取，保留现有工作区，不提交、推送、部署或操作业务数据。

以下五源分工用于工作记录类，不要求云端提交类逐源扫描。

## Agent-CC
- 输入：用户选定范围内的 CC 记录（timestamp 转用户本地时区），或指定材料。
- 职责：按统一契约提炼素材，必要时核对工具结果；返回素材或写入指定的 `$PREFIX-cc-draft.md`。

## Agent-Codex
- 输入：用户选定范围内的 Codex 记录，包括需要的归档；先定位主会话，合并子任务的重复上下文。
- 职责：同上，返回素材或写入指定的 `$PREFIX-codex-draft.md`。

## Agent-Zcode
- 输入：按 SKILL.md「ZCode 会话查询」只读取得的范围内记录，排除 synthetic 注入。
- 职责：同上，返回素材或写入指定的 `$PREFIX-zcode-draft.md`；标题与工具名本身不证明完成。

## Agent-Minimax
- 输入：按 SKILL.md「MiniMax Code 会话查询」取得的范围内真实消息，跨天会话以消息时间核对。
- 职责：同上，返回素材或写入指定的 `$PREFIX-minimax-draft.md`；必要时深读结果，过滤系统注入与重复研究节点。

## Agent-Antigravity
- 输入：按 SKILL.md「Antigravity 会话查询」取得的范围内记录，合并桌面端与 CLI 相同会话的互补正文。
- 职责：同上，返回素材或写入指定的 `$PREFIX-antigravity-draft.md`；只有元数据而缺正文时披露缺口。
