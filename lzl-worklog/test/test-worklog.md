# worklog 测试门

端到端自检：验证"记录→去重→汇报"主链路。用 fixtures 假数据，不碰真实会话。

## 断言清单
1. **去重**：对 fake-log 再次记录 `[记住我]` → 被跳过，日志仍只 1 条。
2. **时区**：fake-cc 的 UTC timestamp 转本地后 = 本周内日期（不因时区漏出本周）。
3. **汇报**：读 fake-log + 扫 fake 会话 → 周报含 `## 需求：记住我`，四段（背景/方案/落地/结果）齐全。
4. **不编造**：fake 会话无"结果"数据 → 对应 `**结果**：待补充`，无编造数字。
5. **边界**：清空日志+会话 → 提示"本周无记录，可先记录一下或梳理一下"。
6. **ZCode 源**：用 python 建临时 sqlite（`session`/`message`/`part` 三表，含 1 条起点内、1 条起点外、1 条 `synthetic=1` 注入消息），按 SKILL.md「ZCode 会话查询」跑 → 起点内会话及其真实用户消息被列出，起点外与 synthetic 被排除。
7. **闸口**：依次模拟裸调用、模式 A 范围选择、候选确认、汇报清单确认，验证每道闸口展示选项后**结束回复停轮**，未获用户明确选择前无扫描/落盘；重点防**自问自答**（同一回合提问又自行回答继续执行，2026-08-16 CC 实测事故）。

## 运行
把 fixtures 复制到 /tmp，按 SKILL.md 流程实跑一次汇报，逐条核对断言。
