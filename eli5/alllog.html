ELI5 讲解 · alllog

alllog：从聊天记录里挖简历素材

把你在四个 AI 助手里干过的所有活，翻出来按项目归堆，挑出值得写上简历的那些。
一句话类比：worklog 是帮你记这周的笔记，alllog 是毕业整理档案柜——它把你和 Claude Code / Codex / ZCode / MiniMax Code 的全部历史聊天翻一遍，按项目聚类，提炼出"做了什么、用了什么技术、结果多好"，列成编号清单让你勾选，最后汇总成一份按项目分组的简历素材库。

和 worklog 的核心区别

📅

worklog

只看本周，给老板看。周一命名一份日志。

🗄

alllog

看全部历史，给未来的自己写简历用。按天累积，永不清理。

一条红线：只能手动唤醒

对话里出现"素材库""记简历"这些词，不会自动触发 alllog。必须你显式打 /alllog。

为什么？因为它要全量翻你的历史会话（可能上千个），是个重活，绝不能被一句闲聊误触发。

怎么用

/alllog
全量梳理（挖简历素材）
接着上次挖（续挖模式：从上次停点继续，最常用）

挖一次的完整流程

覆盖度回执：不许静默偷懒

每次给你看候选，必须同屏附一张四源统计表——这是被实测教训逼出来的规矩：曾经 AI 只挖了一个数据源，另外两个静默放弃，用户反问"只有这几天的吗"才穿帮。

| 源 | 扫描数 | 纳入 | 排除（原因） | |--------------|--------|------|-------------------| | CC | 120 | 86 | 空壳 14 / 日期外 20 | | Codex | 0 | 0 | 该时段真空（写明！）| | ZCode | 31 | 25 | 日期外 6 | | MiniMax Code | 12 | 9 | 纯注入 3 |

纳入为 0 必须写明是"真的没有"还是"方法失败"——禁止静默缩水。

素材存哪、怎么变成素材库

$ALLLOG_DATA_ROOT/素材/ ← 数据根：环境变量可改，默认 ~/alllog ├── 日志/2026-09-29.md ← 唯一事实底账，只追加 └── 整理/2026-09-29.md ← 汇总快照（同日重生成），给做简历时读
素材库

它读全部日志，按 [项目名] 归组，每项目五段：背景 / 技术栈 / 亮点 / 结果 / 素材记录。缺失的写"待补充"，禁止编造量化数字。
