# 腾讯文档适配器指南（Tencent Docs Adapter）

本指南说明如何将 `lzl-excel` 的标准数据写入腾讯文档（Tencent Docs / docs.qq.com）在线表格。

---

## 1. 接入方式

腾讯文档主要支持以下几种集成与落地路径：
1. **腾讯文档开放平台 API（Open API）**：
   - 官方提供了针对在线表格（Smart Sheets / Standard Sheets）的 RESTful API；
   - 支持创建在线表格、创建子表（Sheet）、批量写入单元格值及设置单元格格式。
2. **结构化剪贴板与导入（Clipboard / CSV / XLSX）**：
   - 生成带多行嵌入与格式保护的标准结构（TSV / 带引号换行的 CSV）；
   - 在已打开的腾讯文档页面中，通过自动化工具（如 Playwright / ego-browser）或用户直接粘贴快速落盘。
3. **本地 XLSX 桥接上传**：
   - 通过 Python/Node 脚本先生成格式完全就绪的 `.xlsx` 文件（内含多 Sheet、冻结行、自动换行与居中样式）；
   - 上传或一键导入到腾讯文档云端空间。

---

## 2. 腾讯文档排版关键对齐点

为了达到与飞书表格一致的高质量呈现，腾讯文档中需重点保证以下特性：

1. **单元格内多行换行保护**：
   - 腾讯文档在接收多行文本时，必须使用带有引号转义的标准换行符（`"\n"`），否则粘贴或导入时会被误判为跨行切分；
   - 确保 `原背景/问题` 与 `本次实际改动` 列的编号换行完整保留。
2. **多 Sheet 对应多仓库**：
   - 同样严格执行一仓一 Sheet 原则；
   - 在底部的 Sheet 切换标签栏保持与仓库同名。
3. **冻结与换行**：
   - 开启首行冻结（视图 -> 冻结首行）；
   - 选中全表开启“自动换行”，避免长文本溢出或遮挡。
4. **变更日志页居中规范**：
   - 变更日志页的日期大标题必须设置水平居中对齐，正文条目左对齐。
